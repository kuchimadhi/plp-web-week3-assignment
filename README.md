# plp-web-week3-assignment
Budget Tracker
Project Description

This project is a simple Budget Tracker webpage created using HTML and CSS. It demonstrates a clear visual identity for a budgeting application, including a header, transaction form, transactions table, and design notes.

The project focuses on creating a clean, responsive, and user-friendly interface.

Files in the Project
index.html – Contains the structure and content of the Budget Tracker webpage.
style.css – Contains the styling, colors, typography, spacing, borders, and responsive design.
README.md – Provides information about the project and how to use it.
Features
Responsive webpage layout
Budget Tracker header and navigation
Transaction entry form
Transactions table
Clear typography and color scheme
Consistent margins and padding
Borders and rounded corners
Visual design notes
How to Run the Project
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
The Budget Tracker webpage will be displayed.

You can also use Visual Studio Code with the Live Server extension to preview the webpage.

Technologies Used
HTML5
CSS3
Visual Identity

The design uses a consistent color palette, typography, spacing, borders, and rounded corners to create a clean and professional Budget Tracker interface.
